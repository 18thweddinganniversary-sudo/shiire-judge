# 仕入れ判断 v9.17 二択完成・棚判定版

## 方針
- 表面の最終判定は 🟢 / 🔴 のみ
- データ不足・手数料不足・ASIN/入数不一致はすべて 🔴「見送り」の理由として扱う
- 🟢は商品一致・実手数料・利益・利益率・ROI・価格安定・競争・鮮度・回転の必須条件を全通過した時だけ
- 「近くをチェック」は関連商品ではなく、最初に読んだ商品の同じ棚・同じ陳列ケースを基準にする
- 候補が弱ければ無理に出さず「この棚の候補はありません」

## 9.16で追加した修正
- 黄色/橙/灰の最終シグナルをDOM最終段でも赤へ統一
- 「手数料データ不足」など第三状態を 🔴見送り に統一
- 「同シリーズの候補を探す」→「同じ棚をチェック」
- 候補から候補へ移動しても基準棚を維持。通常の別商品を開けば基準棚を更新

- v9.17: 一覧の「要確認」「慎重」「少量なら検討」「データ不足」を最終表示では「見送り」に統一
- 「条件未達」は赤表示に固定し、緑と誤認しないようにする
